# Mini-ERP & Invoicing System

A lightweight, robust Enterprise Resource Planning (ERP) and invoicing backend built with **Django (Python)**. Designed to manage financial operations, client relationships, taxation, and transactional records seamlessly.

## 🚀 Features
- **Client Management**: Track and manage client profiles, contact information, and billing details.
- **Tax Rate Control**: Dynamic management of regional and global tax rates.
- **Invoicing & Line Items**: Automated creation of invoices linked with detailed itemized billing.
- **Transaction Ledger**: Secure financial tracking and transaction records.
- **Django Admin Integration**: Full administrative control with customized database models.

## 🛠️ Tech Stack
- **Backend**: Python, Django
- **Database**: SQLite (Local Development)
- **Environment**: Virtual Environment (venv)
